# SellStack

Launch dashboard for starting an online selling business — dropshipping, Amazon FBA, print-on-demand, social commerce, and more.

## What's inside

- **35+ platforms** across marketplaces, storefronts, sourcing, fulfillment, POD, wholesale, social commerce, and automation
- **Business model picker** with recommended starter stacks
- **Filterable directory** (capital, difficulty, category, beginner picks)
- **Side-by-side compare** (up to 4 platforms)
- **Persisted launch checklist** (saved in your browser)
- **Budget-based starter paths** for week-one execution

## Run locally

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Notes

Fee and cost figures are approximate planning snapshots from public research. Always verify current rates on each platform before selling.
